## Итерации
- [x] 1. Каркас: Vite + Phaser 3 + TS, загрузка ассетов из манифеста, тестовая карта
  - BootScene грузит всё из манифеста и сверяет число кадров с cols×rows (расхождений нет)
  - TerrainRenderer: вода, пена, автотайлы 16 вариантов, тени, скалы (к земле/к воде), лестницы, 3 уровня высот
  - IslandGrid: высоты, лестницы, проходимость `canStep` с учётом перепадов (для A* в итерации 3)
  - TestMapScene: витрина всех юнитов, клавиши 1–5 переключают анимации, F — разворот; камера WASD/ПКМ/колесо
- [x] 2. Процедурная генерация острова (simplex + маска, flood fill, точки высадки, сид)
  - `mapgen/IslandGenerator.ts`: шум + эллиптическая маска → сглаживание → один остров без озёр → плато (морф. открытие, заполнение щелей) → уровень 3 (иногда) → лестницы → проверка связности (недостижимые плато опускаются) → 3–6 точек высадки с чистой водой перед ними → 2–5 домов → деревья (не ломают связность), кусты, камни, овцы
  - Все параметры — `ISLAND` в `data/balance.ts`
  - `npm run gen:test [N] [сид]` — прогон генератора без браузера + ASCII-карта. На 300 сидах: 0 провалов, 1 попытка, ~2 мс/остров
  - В игре: `?seed=123` в адресе, N — новый остров, [ ] — соседний сид, G — отладочная сетка, U — витрина юнитов
- [x] 3. Отряд игрока: выбор, движение строем, анимации, замедление времени
  - Клик по отряду / клавиши 1–4 / карточка внизу — выбор; клик по земле — марш; ПКМ или Esc — снять выбор
  - Пока отряд выбран, время плавно замедляется до 0.2× (`TIME` в balance.ts)
  - Поиск пути: поля потоков (Dijkstra от цели, кэш) с учётом лестниц и скал; прямой путь, если он свободен
  - Строй: места вокруг точки по клеткам (по 4 в клетке) + расталкивание юнитов
  - Конечный автомат юнита: idle → move → engage → attack → dead
- [x] 4. Враги на лодках, бой, смерть, отталкивание и утопление
  - Лодки идут по воде от края карты (BFS по воде + сглаживание) к точкам высадки; стрелки у края экрана заранее показывают, откуда придут
  - Волны по бюджету «очков» с учётом сложности; следующая волна — когда осталось ≤25% врагов или прошло 50 с
  - Враги: гоблин с факелом, гарпунщик, тролль (замах + удар по площади), гоблин с динамитом, бочка-камикадзе, скелет со щитом, шаман, минотавр (босс)
  - Отбрасывание: юнит может слететь с плато (урон от падения) или в воду (тонет)
  - Снаряды по дуге: стрелы, гарпуны, динамит, шары шамана; щит пехоты/скелетов блокирует снаряды спереди
- [x] 5. Классы, дома, лечение в домах, поджог домов
  - Ополчение (до выбора класса), пехота (щит), лучники (сильны издали, слабы вплотную), копейщики (длинная дистанция, отбрасывание + оглушение, держат строй)
  - Враги у двери незащищённого дома поджигают его (полоска поджога), дом горит и рушится — награда за него теряется
  - Клик по дому выбранным отрядом — отряд прячется внутри и восстанавливает по солдату каждые 2 с; если дом подожгут, отряд выбрасывает с уроном
  - Гибель командира = отряд потерян (солдаты гибнут следом)
- [x] 6. Экономика, апгрейды, способности, предметы
  - Монеты за каждый уцелевший дом (3–5 в зависимости от дома), `ECONOMY` в balance.ts
  - Экран «Отряды»: выбор класса на 1-м апгрейде (ополчение → пехота/лучники/копейщики), уровни 2–3 (+HP, +урон; в отряде всегда 9 бойцов), покупка/усиление способности
  - Способности с перезарядкой (кнопка на карточке отряда или Q): щитовой рывок, залп стрел, круговой удар копьями
  - Предметы (1 на командира): Рог (+20% скорость), Щит (+25% HP), Бомба (+35% отбрасывание); находятся на островах, надеваются/снимаются на экране «Отряды»
- [x] 7. Карта кампании, permadeath, финальный остров
  - Граф островов (6 колонок по 2–3 острова + финал), миниатюры — настоящие острова по их сидам
  - Шторм наступает слева (~1 колонка за 2 хода) и поглощает непройденные острова
  - Каждый ход: остров + до 3 отрядов; воевавшие отряды отдыхают следующий ход
  - Награды островов: монеты за дома, иногда предмет или новый отряд; наём ополчения за монеты
  - Гибель командира — отряд удаляется из кампании навсегда (вместе с предметом)
  - Финальный остров: +1 волна, усиленный бюджет и минотавр
  - Итоги боя → карта; победа/поражение в кампании → итоги → новая кампания с новым сидом
  - Кампания сохраняется в localStorage («Продолжить» в меню)
- [x] 8. Полировка: эффекты, звук, баланс в `src/data/balance.ts`
  - Звуки синтезируются WebAudio (в паках аудио нет): удары, стрелы, всплески, взрывы, рог волны, огонь, клики; вкл/выкл в меню
  - Эффекты: пыль, взрывы, брызги при утоплении, огонь на домах, вспышка при попадании, искры блока, тряска камеры от тролля/минотавра
  - Все игровые числа — в `src/data/balance.ts` (острова, юниты, волны, дома, экономика, кампания, ИИ)
  - Настройки: числа урона, звук (localStorage)

## Как играть
- `npm run dev` → http://localhost:5173
- Меню: «Новая кампания», «Продолжить», «Быстрый бой» (случайный остров, 4 готовых отряда)
- В бою: клик по отряду (или 1–4, или карточка внизу) — выбрать, время замедляется; клик по земле — идти; клик по дому — войти и восстановить солдат; ПКМ/Esc — отмена
- Q или кнопка на карточке — способность выбранного отряда; Пробел — пауза; F — ×2; WASD/ПКМ — камера; колесо — зум
- Отладка (только dev): `?seed=123` — сразу бой на этом острове; G — сетка проходимости; H — текстовая панель; E — враги у курсора; N — новый остров; U — витрина юнитов; M — выход в меню из быстрого боя
